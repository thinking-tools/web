Crafted for Peace-of-Mind Computing

We're an unruly crew of open-source tinkerers, out to prove that technology can feel like fresh air rather than background noise.

🌿 Calm by design

Interfaces that whisper, not shout. Quiet defaults, respectful notifications, and zero "growth-hack" hijinks.

👑 Sovereign by architecture

Everything we build can run fully on your own hardware or a cloud you choose. No lock-in, no shadow dependencies.

✨ Convenient by craft

Setup flows that take minutes, not afternoons. Sensible presets, one-command updates, and human-readable docs.

🔐 Private & transparent by principle

We never collect telemetry by default, and every line of code is open for you—and the world—to inspect, fork, and remix.

Post-Quantum Ready

LatticeStore

An open-source, post-quantum-ready "S3-layer" framework that hides the complexity of modern cryptography behind a single, edge-friendly SDK.

Key Features:

  • Client-side PQC using NIST-selected algorithms
  • Works with any S3-compatible storage
  • One SDK for Android, Node, and browsers
  • Fully open-source (Apache 2.0 / MIT)

Year 1 Deliverables:

  • LatticeStore RFC v0.9
  • Rust core + CLI on crates.io
  • Android & JS bindings
  • Edge gateway container
